## 2. AI 输入契约（automation 必读文件，全部服务器路径）

1. `daily/{D}/行情快照.json` —— 指数、期指贴水/仓差、宽度、涨停池、晋级率、封板质量、昨日涨停反馈（**替代原 TDX 单批并发取数**）
2. `daily/{D}/板块全量.json` —— 46 L1 方向景气、3 日平滑分、热力图行
3. `daily/{D}/涨停质量.json` —— 五维分、连板天梯、首板专区
4. `daily/{D}/竞价预期基准.md` —— 明日三档基准（概率分布，禁当指令）
5. `{SHORT_TERM_DATA_DIR}/{D}/snapshot.json` —— 市场概览/晋级率（与 1 交叉核验）

⛔ 缺任何一份：对应段落标「数据不可用」，**禁推算、禁 WebSearch 补数**；⛔ 成本类文件永不进入输入。

## 2.5 思考链路规范（AI 内部推理顺序，产物须可追溯）

AI 复盘不是自由写作，按以下**固定六步**推进，每步结论落进对应产物段落：

| 步骤 | 思考内容 | 判据（不可替换） | 落点 |
|---|---|---|---|
| 1 数据核验 | 5 份输入逐一验存在性与状态字段（snapshot 数据源状态全 ok？） | 任一缺 → 对应段落「数据不可用」，禁推算 | 全文 |
| 2 结构判定 | 指数位置 + 量能同比 + 宽度背离 | 结构分 = 指数 25 + 量能 15 + 宽度 10；宽度与指数背离 = 最早「修复中断」读数 | 段二、三 |
| 3 情绪定位 | 涨停家数 / 高度断层 / 炸板率 / 晋级率 / 跌停家数 | 温度计 100 = 涨停 30+高度 20+炸板 20+晋级 15+跌停 15，折半入总分；炸板率 >25% + 高度断层 ≥2 级 → 路径二 | 段三、四 |
| 4 方向景气 | 热力图 TOP 方向 + 方向锚规则 | 仅「连续 1 日成立且前日未登顶」可候选；当日首次登顶只进观察层，**禁点名龙头**；防御类首登满足三条件可进候选观察 | 段五、六 |
| 5 期指独立预警 | 当月升贴水结构 + 仓差 | 结构变化是**独立反抽预警**，持续 2 日才升级信号；远月贴水>近月=谨慎 | 段七 |
| 6 预案生成 | 明日三档基准 + 候选池 | 基准是概率分布禁当指令；候选池宁缺毋滥；路径判定拆指数/情绪两栏，不一致判「背离结构」 | 段九、十 |

写作风格硬约束：结论先行、确定性点名最强、禁并列 hedging；数据只出现一次；盘面总结必含期指表。

## 3. AI 输出契约

### 05_复盘与明日预案.md

- 段七「股指期货跟踪」必含：当月升贴水结构、仓差变化、结论（远月贴水>近月=谨慎；结构变化持续 2 日才升级信号）；

- 结论先行、确定性点名最强、禁 hedging。

`date / structure_score / sentiment_score / sentiment_thermo(=50制×2) / total_score / gate / limit_up / limit_down / max_board / hero_offset=238.8×(1−分/100) / sentiment_detail{5项各含raw,score,full,note} / structure_detail{index,volume,breadth,chan_state,center_zd,center_zg,last_stroke,macd,wave} / sectors[] / indices{4指数 close,chg,amount_yi} / futures[] / futures_note / candidate_pool_today_result / plan_tomorrow / lessons`

## 4. 质量门（automation 收尾自检，任一失败即告警不发布）

1. **净化 grep**：三产物禁 `持仓|成本|浮盈|浮亏|安全垫`；
2. **提取自检**：md_to_replay 输出 hero/body/style 均非空；
3. **热力图自检**：同一方向不得出现两行；
4. **fusion 自检**：段二须含 `缠论视角` 与 `波浪视角`；
5. **评分互斥**：结构/情绪分口径不得互相污染（结构 50 = 指数25+量能15+宽度10；情绪 50 = 温度计折半）。
