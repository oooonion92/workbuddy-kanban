# 数据契约 · 看板渲染器输入（D1 视觉层）

> 视觉层 = `build_dashboard.py` + `build_entry.py` + `md_to_replay.py`，**代码原封不动**，云端以 `KANBAN_ROOT` 指向 git 仓库根运行。本契约定死渲染器的全部输入，云端数据管道按此交付。

## 1. 每日文件（`{D}` = YYYYMMDD）

| 文件 | 生产者 | 渲染器用途 | 缺失行为 |
|---|---|---|---|
| `daily/{D}/05_复盘与明日预案.md` | **AI 写作**（节点⑤） | replay.html 融合源（十段式，fusion 官方锚点） | 无法渲染 replay |
| `daily/{D}/复盘数据.json` | **AI 写作**（节点⑤） | 双维评分圆环、hero 弧线（`hero_offset=238.8×(1−分/100)`）、指数卡、期指段、候选池、预案 | 看板主体缺省 |
| `daily/{D}/行情快照.json` | `fetch_snapshot.py` | 市场总览客观区（涨停/跌停/炸板/晋级率/封板质量/宽度/期指贴水） | 客观区标「数据不可用」 |
| `daily/{D}/板块全量.json` | `build_sector_full.py` | 板块热力图（TOP18 L1 方向）、方向景气 | 热力图缺省 |
| `daily/{D}/涨停质量.json` | `build_zt_quality.py` | 连板天梯两段并列（首板专区 + 2板+ 质量分） | 天梯缺省 |
| `daily/{D}/竞价预期基准.json/.md` | `build_auction_baseline.py` | 明日推演段 | 明日推演缺省 |
| `daily/{D}/first_board/{D}_eod/eod_state.csv`(+manifest/排除明细) | 1J2 skill（范围外，格式不变） | 首板专区 `fb_*` 字段，**不重算** | 首板专区缺省 |

## 2. 依赖文件（打分脚本输入，非渲染器直接输入）

| 文件 | 生产者 | 消费者 |
|---|---|---|
| `{SHORT_TERM_DATA_DIR}/{D}/zt_pool.csv`（17列）+ zb/dt/previous_zt_feedback + snapshot.json | 池包采集器 | fetch_snapshot、build_zt_quality、build_auction_baseline |
| `{DETAILS_DATA_DIR}/全部Ａ股{D}.xlsx`（23列，万元/文本市值格式） | collect_a_details.py（新） | build_sector_full、build_zt_quality、build_auction_baseline |
| `{DETAILS_DATA_DIR}/全A快照_{D}.json` / `全A竞价快照_{D}.json` | collect_a_details.py（新，自累积） | 次日 昨成交额/昨涨幅/竞价列 |

## 3. 渲染器输出与发布

- `daily/{D}/dashboard.html`（每日详细存档）、`daily/{D}/replay.html`、`daily/entry.html`（主入口，覆盖式）
- `daily/dashboard.html` 为跳转存根（构建器自动生成，禁手工编辑）
- 发布：云端直接由 `push_kanban.py` 同目录逻辑替换为 cp/rsync 到 `/var/www/kanban`（本地推远端 → 云端内部拷贝）
- ⛔ 产物净化：grep 禁 `持仓|成本|浮盈|浮亏|安全垫`

## 4. 渲染验收（P3 双跑期，每日执行）

1. 同一数据包本地/云端各渲染一次 → HTML diff 为空（除时间戳行）；
2. 375px / 768px / 1440px 三档 viewport 截图与本地版比对；
3. 跑后三检：融合源提取告警（hero/body/style 非空）+ 热力图同方向两行 + 净化 grep 全部通过。
