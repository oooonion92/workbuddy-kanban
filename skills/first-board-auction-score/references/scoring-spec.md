# 冻结模型规范

版本first-board-auction-v1-20260922。models.json保存精确系数、训练中位数、1%/99%截尾、均值标准差和经验参考分布，日常不训练。

首板六因子：一字状态；1−首封交易分钟/240；1−末封交易分钟/240；ln(1+封板资金/成交额)；ln(1+100×封板资金/流通市值)；ln(1+炸板次数)。9:25按0分钟计，午休扣90分钟。每项截尾后z=(x−均值)/标准差，分数=100/(1+exp(−(截距+Σβz)))。系数不是因果权重。

首板模型alpha=10，用训练＋校准1810条拟合，评分日截至20260828，其最后结果截至20260831，因此最早用于20260831收盘。研究2472条、50日；历史留出662条、15日，晋级111条；核心AUC0.636893，每日前20%晋级39/139。该历史区间被多次查看，属于探索而非新前瞻验证，无可成交收益回测。

开盘预期沿用17因子岭回归，基于普通10%板混合训练，不冒称首板专属。包括板高、一字、首末封、封单比例、炸板、换手及平方、流通市值、成交额较昨倍数、近5日涨幅、同行业其他涨停数和占比、行业最高板、市场涨停数、封板率。预测限制在普通10%价格上限／下限（前收盘×110%／90%，四舍五入到分）。除权／特殊交易规则须待核验。

竞价残差r=g−μ，g为最终开盘相对参考昨收的涨幅百分数。主阈值q20=−3.2959383007202194，q80=2.5239430446936617；相等归符合。竞价分=100×校准残差≤r的比例。它与概率首板分分别输出，不混成未经检验的综合分。

μ接近涨停上限时，价格超预期可能不可达，属于兑现强预期；不降低门槛凑标签。首板分层残差阈值约[−3.1790,2.2021]仍为探索，不默认启用。

量能Q=100×竞价额/昨全天成交额，目标ln(1+Q)，同17因子、alpha=100岭回归。量能残差阈值约[−0.346282,0.379118]，仅辅助，不用它覆盖价格评价。未训练过竞价后的晋级概率，不能伪造。

所有eod文件保存输入哈希、模型哈希和派生输入，次日只读该冻结版本。缺近期涨幅允许中位数填补，关键字段缺失排除。新版本必须另行验证并标记生效日。
