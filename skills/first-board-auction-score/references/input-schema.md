# 输入规范

## 收盘

`<pool-dir>/<YYYYMMDD>/snapshot.json`、`zt_pool.csv` 和 `<details-dir>/全部Ａ股YYYYMMDD.xlsx`。支持旧GB18030制表文本xls；同日补充xlsx覆盖匹配证券，其他重复代码报错。

涨停池必须有：交易日期、代码、名称、涨跌幅、最新价、成交额、流通市值、换手率、封板资金、首次封板时间、最后封板时间、炸板次数、连板数、所属行业。金额为元，换手率为百分数（5%输入5）。代码六位字符串，时间HHMMSS或HH:MM:SS。snapshot必须声明涨停池成功。

details使用代码、现价、涨幅%、最高、最低、昨成交额、总金额，金额为万元。近期表现从最近5个确认的交易日日涨幅复合计算。脚本不读取次日收盘作为特征。

普通主板代码00/60开头；排除ST、退、N/C特殊名称、非首板、行情冲突等。价格容差0.011元、涨幅容差0.15个百分点。最高=最低才记全天一字。

## 最终竞价快照CSV

UTF-8 CSV必需表头：

```csv
代码,竞价日期,快照时间,开盘价,参考昨收,竞价金额元
```

代码唯一；日期YYYYMMDD；快照时间为上海当地`YYYY-MM-DD HH:MM:SS`，目标日09:25:00以后。价格与金额均为元，必须是已确定的最终开盘字段，不是盘中最新价或9:25前虚拟撮合价。

部分股票缺行或开盘缺失允许，保留股票标待核验。参考昨收相对前晚收盘差异超过0.2%待核验。竞价金额缺失或≤0只失去量能标签。错日期、重复代码整体拒绝。模型哈希、前晚状态文件哈希变化拒绝。

## details历史回放

显式 `--kind details-replay --replay` 读取文件名日期及今开、开盘%、开盘金额。开盘金额万元转元，通过今开与开盘%恢复参考昨收后校验。不用当天收盘价、涨幅、高低价作竞价结论；该路径不证明9:25当时已经保存数据。
